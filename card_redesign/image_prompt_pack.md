# Image Generation Prompt Pack for the 49 MTC Cards

## Global Rule

Generate only the visual scene or object. Do not render text inside the image. The verified scientific text will be added later using the card template.

## Shared Prompt Base

Use this base for every card:

```text
Use case: scientific-educational
Asset type: square visual element for an academic knowledge card
Style/medium: high-quality photorealistic editorial image, realistic scale, not cartoon, not toy-like
Composition/framing: square 1:1 image, one or two main visual elements, clean upper third reserved for later text overlay
Lighting/mood: natural daylight or clean studio light, professional, credible, engaging
Color palette: restrained technical palette, neutral background, subtle category accent
Text: no text, no labels, no logos, no numbers, no watermark
Constraints: avoid clutter, avoid decorative icons, avoid exaggerated futuristic elements, avoid brand marks
```
