# Visual Quality Audit

## Purpose

This file tracks visual readiness for the 49 generated MTC card images. It must be updated after each image-generation batch. A card is not ready for pilot composition until the visual decision is `accepted`.

## Status Legend

- `not generated`: no image exists yet.
- `revise`: image exists but requires prompt/content correction.
- `reject`: image violates a rejection rule.
- `accepted`: image passed all inspection criteria.
