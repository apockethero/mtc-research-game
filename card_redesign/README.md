# MTC Card Redesign

This folder defines the redesign system for the full 49-card MTC deck.

## Goal

Transform the existing cards into a complete scientific communication instrument for the article and the exploratory pilot. The redesigned cards must be visually consistent, traceable, readable and suitable for comparing evidence from the state-of-the-art corpus.

## Files

- `design_spec.md`: visual and content rules for the redesigned deck.
- `card_template.tex`: LaTeX/TikZ template for generating card prototypes.
- `deck_redesign_matrix.md`: tracking matrix for all 49 cards.
- `final_card_text_49.md`: consolidated final text fields for all 49 card templates.
