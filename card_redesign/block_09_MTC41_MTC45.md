# Block 9 Redesign Plan: MTC41--MTC45

## Editorial Status

This block covers accessible e-tricycle design, maintenance strategy, lightweight frame design, safety verification and three-wheeler motor design. MTC41--MTC44 have verified stable author-year-topic keys, and MTC45 now uses a verified three-wheeler-specific PMBLDC motor source.

## Block Function in the Article

Block 9 is important because it connects the deck to three audiences at the same time: users and inclusive mobility needs, engineers working on structure and safety, and designers choosing electric propulsion components. This makes the block useful for the pilot because participants can compare whether cards help non-specialists access technical information without losing methodological caution.
