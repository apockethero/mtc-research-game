# MTC Card Design Specification

## Purpose

Each card must work as a compact evidence unit for navigating the state of the art on electric motor tricycles. The card is not a decorative summary. It is an instrument for comprehension, comparison and traceability.

## Physical Format

- Output format: square card.
- Digital size target: 512 x 512 px or scalable vector/PDF equivalent.
- Print-safe equivalent: 90 mm x 90 mm.
- Margin: minimum 4 mm.
- Orientation: fixed square layout for all 49 cards.

## Required Content Fields

Each card must include:

1. Card ID: MTC01--MTC49.
2. Thematic category.
3. Source-quality label: Q1, Q2, Q3, Q4, Proceedings, Thesis, Report, Chapter or NQ.
4. Short title.
5. Core idea.
6. Evidence type: experiment, simulation, survey, case study, review, design, model, policy analysis or report.
7. Main contribution.
8. Limitation or caution.
9. Traceability code.

## Visual Hierarchy

1. Top band: Card ID, category and source-quality label.
2. Title zone: short title, maximum two lines.
3. Evidence zone: method/evidence type and core idea.
4. Contribution zone: main contribution.
5. Caution zone: limitation or interpretive warning.
6. Footer: traceability code and source key.

## Color System

Use category colors to help grouping, not decoration.

- Accessibility: teal.
- Acceptance/service quality: blue.
- Structure/ergonomics/safety: red.
- Propulsion/energy/sizing: amber.
- Logistics/applications: green.
- Policy/socioeconomic context: violet.
- Review/method/supporting EV evidence: gray.

The source-quality label must use a separate neutral badge so quality is not confused with topic.

## Typography

- Use a sans-serif family for legibility.
- Avoid long paragraphs.
- Use short evidence blocks.
- Title: 11--13 pt equivalent.
- Body: 7--9 pt equivalent.
- Footer: 5--6 pt equivalent.

## Scientific Constraints

- One central idea per card.
- No unsupported generalization.
- No claim stronger than the source.
- No hidden source: traceability must be explicit.
- Limitations must be visible.
- Weak or non-indexed sources must be labelled, not hidden.

## Pilot-Specific Requirements

The deck must support these participant tasks:

- compare cards by theme;
- identify clear and unclear cards;
- explain concepts to a non-specialist;
- connect at least two cards in a short explanation;
- detect which cards require more context.

## Completion Criteria

A card is ready for the pilot only when:

- source mapping is verified;
- content fields are complete;
- text fits the template;
- visual hierarchy is readable;
- limitation/caution is present;
- traceability code is present;
- category and quality label are accurate.
